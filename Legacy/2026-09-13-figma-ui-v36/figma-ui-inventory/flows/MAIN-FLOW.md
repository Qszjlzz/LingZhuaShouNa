# 页面关系与流程

## 核心闭环

```text
SPW-SPC-001 空间首页
  -> SPW-CAP-001 多角度采集
  -> SPW-CAP-002 采集预览
  -> SPW-CAP-003 AI 识别中
  -> SPW-CAP-004 识别确认
  -> SPW-PLN-001 方案输入
  -> SPW-PLN-002 风格与标签
  -> SPW-PLN-003 参考图片
  -> SPW-PLN-004 方案预览
  -> SPW-EXE-001 区域选择
  -> SPW-EXE-002 执行步骤
  -> SPW-EXE-003 区域完成
  -> SPW-EXE-004 完成照片
  -> SPW-EXE-005 前后对比
  -> SPW-SPC-004 已完成空间 / SPW-COM-005 发布完成案例
```

## 底部导航

底部导航是跨页面的共性组件，但选中态不同。每个页面记录必须单独写明：

| Tab | 页面组 | 进入后默认页 |
| --- | --- | --- |
| 空间 | 空间档案、当前进度和成果 | `SPW-SPC-001` |
| 拍摄 | 采集、识别和确认 | `SPW-CAP-001` |
| 分类 | 物品库和分类管理 | `SPW-CAT-001` |
| 执行 | 当前方案和步骤 | `SPW-EXE-001` |
| 社区 | 案例、评论和复刻 | `SPW-COM-001` |
| 个人 | 计划、徽章和日程 | `SPW-PRO-001` |

## 页面高度规则

- 固定页面：内容在一个 `390 x 844 pt` 画板内完成，不模拟滚动。
- 滚动页面：记录 Figma 内容高度、滚动方向、首屏可见范围和底部固定控件。
- 弹层页面：记录背后的页面、遮罩透明度、弹层高度、圆角和关闭方式。
- 长图/展板：先拆出独立手机画板，再决定是否是一个滚动页面；不能直接把展板当作 App 页面。
