# 已读取的视觉 Token

这些值来自 Figma 右侧 Properties 面板的真实图层读取，不是从截图估算。后续页面实现应优先复用项目中的 `SmartPawStyle` 和 `FigmaFont`，再用每页记录覆盖差异。

## 当前证据

| Token | 值 | 读取位置 | 备注 |
| --- | --- | --- | --- |
| 页面暖色背景 | `#F6F1EB` | `ShootFlow`、`ClassificationScreen` | 多个页面共用 |

| 标准固定画板 | `390 x 844 pt` | `ShootFlow`、步骤页 | 采集和执行固定页 |
| 滚动分类页 | `390 x 1155 pt` | `ClassificationScreen` | 需要 ScrollView |
| 滚动成果页 | `390 x 1395 pt` | `对比图` | 需要 ScrollView |

## 当前判断

- 字体优先使用 `PingFang SC`，不要用系统默认字体替代后再宣称视觉一致。
- 页面底部导航与底部操作栏需要区分：前者是跨页面组件，后者是执行流程的动作区。
- `390 x 844` 是部分固定手机画板的内容尺寸；`390 x 948` 的容器属于带额外底部区域/外壳的总览变体，不能直接当成所有页面标准。
- 颜色、字号和间距仍需按页面逐项记录，Token 表不是全量设计系统。
