# AI图续做：视觉评估与生图保真闸门

日期：2026-10-23，Asia/Shanghai。维护既有 React + WKWebView；本阶段未操作手机、未训练模型，AI图不计入真实独立留出集。

## 本阶段完成

- 点亮流程删除物品数/类别数线性假评分、固定热点和5.5秒假完成。生产命令 space.disorder.analyze 读取本批最新真实拍摄图，使用已启用且授权的视觉服务；严格校验分数、依据和归一矩形。当前空间、照片、设置或扫描代次变化时不接收旧结果。
- 评估页展示返回的主观视觉指数、可见依据与真实区域；无配置/失败/非法结果不造分数，支持取消、重试和显式跳过。使用本批最后照片，叠框与图片采用相同裁剪变换。
- 主线和点亮微调都接入当前偏好的真实预览、原图对比、取消/重试、旧结果失效和显式确认；保留明确的文字方案继续入口。拍后方案页可只选部分物品入本机独立库，不改扫描清单，不冒充云同步。
- 新增原图/结果图双图复核。生产生图入口要求另有已授权的视觉配置；生成结果先做画幅/局部合成，再对比数量、遗漏、复制、身份与固定空间。fail、uncertain、调用失败或取消均不写入预览缓存。旧未经复核缓存由v3提示协议的指纹隔离。
- 复核是模型检查，可能错判，不能视为保真保证；只验证了本次已知坏图会被拒绝，未测出总体误判率或全部正样本通过能力。默认相机/锁屏/真实WKWebView端到端付费路径仍未重跑。
