- 旧拍照入口仅首张调用大模型，后续照片只走本地。现在逐张调用配置且已授权的视觉服务。

- 云端上传最长边2048、JPEG0.85，小件框最小0.005；这是工程参数，未证明准确率提高。
- Responses响应读取全部文本段；非法JSON作为错误处理，不伪装成空场景成功。
- 生产生图提示词提取到StoragePreviewPrompt，明确逐件保留物品、数量、画幅、空间与分区外内容。gpt-image-2请求尺寸根据输入比例选择；供应商仍可能忽略或改图，必须看真实输出。
