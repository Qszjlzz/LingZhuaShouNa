## 已实现

- 生图走真实照片 multipart 编辑接口；`gpt-image-2` 请求不发送不支持的 `quality`、`response_format` 字段。用户主动点击后才发起请求，上传前有原生同意提示。

- Key 通过 Debug 一次导入进入独立 Keychain，App 资源不包含配置文件；成功导入后删除输入文件。
