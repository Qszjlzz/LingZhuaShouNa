# 自主文件夹整理：实现与验证（2026-10-23）

## 实现范围

依据 docs/design/make-intent-20261022.md 已读 V80 需求，在现有 React 分类页增加“我的文件夹 · 自由整理”入口；分类管理页可进入同一入口，原分类与扫描流程保留。

- 用户勾选部分已识别物品入库，以稳定识别 ID 去重，同名不同 ID 的物品仍为独立物品。
- 入库为独立本机快照，含来源空间与识别 ID；调整文件夹不修改或删除原扫描记录，也不重新上传。
- 四列物品/文件夹网格，长按进入整理并轻晃，完成退出；支持系统减少动态效果设置。
- 指针拖到物品中央建夹，拖到边缘调序，拖进已有夹；文件夹内拖序、移出落点及明确的移动按钮/前后箭头提供替代操作。
- 自主文件夹可跨参考类别、打开、改名、添加新识别物品或手动物品、移入/移出，解散后内容回到首页。
- 手动填写名称与参考分类、选本地图片；图片解码后缩至最长边 640，JPEG 编码保存。物品可修改名称和图片。
- 本机 localStorage 保存顺序、成员关系、名称和图片；presentation/personal 使用不同键。写入失败显示未保存错误，不把失败操作留成成功状态。
- 本机库与真实云端存储不同；界面明确说明“本机保存”“暂未同步云端”。
