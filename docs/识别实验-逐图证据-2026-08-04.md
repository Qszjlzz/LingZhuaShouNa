# 识别实验逐图证据（2026-08-04）

## 本轮实现

- YOLOE、YOLO11n 1280 和 YOLO11n 640 不再在首个模型有结果时提前返回。
- 按模型优先级合并候选：YOLOE 结果优先，后续模型只补充空间上不重复的实例。
- COCO 分支改为类别化阈值：书本、电脑、键盘、手机使用 0.35，其余类别保持 0.50，优先补回收纳场景中的小型核心物体。
- 对 YOLOE 低于 55% 的 drinking cup 保留真实 mask 但改显示为“待确认物体”，避免把低置信区域冒充确定类别。
- EdgeSAM 仅对 raster 覆盖率超过 35% 的可疑大区域做二阶段细化，避免移动正常小物体的 mask。
- 当整张图片只剩一个待确认区域时，使用 MobileCLIP 的整图语义作为场景级补充；多物体检测结果不参与重标，避免用场景标签覆盖实例标签。
- Vision/DeepLab 兜底产生的真实 polygon mask 会按轮廓栅格化为 raster mask，保留为低置信度“待确认区域”，不伪造物体类别。

## 10 图真实评测

设备：iPhone 16 Simulator，iOS 18.5。测试：`testYOLOSegmentationEvaluationDatasetReportsScenarioHitRate`。

| 指标 | 本轮结果 |
| --- | ---: |
| 场景类别命中率 | 100%（10/10） |
| 可展示 raster mask 场景率 | 100%（10/10） |
| 平均候选数 | 5.3 |
| 平均候选置信度 | 56% |

原本没有候选的杂乱房间、衣柜、车库样本现在保留了来自真实视觉区域的待确认候选；它们不应被解读为已经准确识别出具体物品。

## 去重调参回归

本轮尝试过 raster mask IoU 和 mask containment 去重。外部杂乱书桌图的测试要求至少 8 个自动 mask；这些 mask 去重实验会误合并真实实例，因此最终保留原先的 box IoU 阈值，不采用 mask 去重实验结果。全量 COCO 阈值降到 0.35 会使厨房候选从 8 增到 10，故改为仅放宽书本、电脑、键盘、手机四类。

低置信杯子校准不会减少候选或 mask，只改变不确定类别的显示；10 图评测中书架样本由“杯子”变为“待确认物体”，其他高置信杯子保持不变。

EdgeSAM 对照中车库样本的异常大区域覆盖率由 `0.666` 降至 `0.219`，10 图候选数和场景命中率不变。

整图 MobileCLIP 在书架图上给出电脑 `0.17`、书本 `0.16`、杯子 `0.13`。只在单个待确认区域时采用该证据后，书架被校准为电脑设备，衣柜为衣物，车库为工具，杂乱房间为待清理杂物；10 图场景命中率由 90% 提升到 100%，候选数和 raster mask 覆盖率保持不变。

## MobileCLIP 对照

同一评测集的语义复核为 70% 命中率、平均置信度 23%，并出现将杂乱区域判为“鼠标”等错误。因此本轮不接入主扫描链路，仅保留为实验性复核能力。

## 剩余问题

- 低纹理和高杂乱图片仍主要依赖待确认区域，具体类别召回不足。
- YOLO11/YOLOE 合并后，桌面和厨房场景仍有同类候选；当前证据表明继续提高去重强度会损失真实实例召回，不能只用候选数量判断改进。
- 场景类别命中率不等于目标级类别精度。真实类别精度仍需要收纳场景数据集微调或经过真实样本验证的专用识别模型；当前场景补充只适用于单个待确认区域。
