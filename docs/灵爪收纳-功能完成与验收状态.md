## 当前真实边界

- 模拟器只能验证静态真实照片识别、mask 对齐、交互和完整闭环；ARKit 世界跟踪与 RoomPlan 必须在支持的真机验证。
- YOLO11n-seg 是 COCO 通用模型。电脑、杯子、手机、书本等常见类别可用，但杂物袋、线缆、纸张和收纳专用品仍可能漏检或错分。
- 实测最弱杂乱房间样本仅识别手袋 33% 和碗具 28%；这证明管线可用，但不能证明跨场景精度达标。
- 当前尚未集成 EdgeSAM/MobileSAM，也没有带人工真值 mask 的 IoU/Dice/边界 F-score 评测集；不过代码里已经有基础的 raster overlap 指标，可用于合成样本和后续真值集接入后的对比。现有 raster mask 明显优于矩形框，但不能诚实承诺已达到参考视频的像素级完美边缘。
- 云端 AI 连接测试需要用户提供自己的兼容 Responses API 服务和密钥；没有密钥时本地规则规划仍可完整使用。
