# 灵爪收纳：视频与现状分析

## 结论先说
当前 `灵爪收纳` 的实现，和参考视频表达的产品完成度，不在一个层级。

视频不是“功能演示”那么简单，而是一条完整的产品叙事：品牌开场 -> 场景痛点 -> 多维采集 -> 方案生成 -> 区域引导 -> 执行步骤 -> 前后对比 -> 档案/社区沉淀。  
现在的 app 虽然已经有扫描、规划、执行、社区、我的这五个入口，但页面呈现仍然偏“通用卡片 + 演示占位图”，没有把视频里的真实体验复现出来。

- 抽取了真实视频 `灵爪收纳/e4f91991caef61ce0e5cfb43f740c2a6.mp4`

  - `灵爪收纳/video-analysis/contact-sheets/`

  - `灵爪收纳/app-analysis/screenshots/00-current-launch.png`

## 视频里真实呈现的东西
参考视频的核心不是“菜单很多”，而是“每一步都在讲清楚用户要做什么”。

1. 开头是强品牌叙事，先把“灵爪收纳”定义成一个空间整理/效率产品。
2. 中段大量使用手机界面、场景照片、AR 框选、步骤卡片，把“识别 -> 分类 -> 规划 -> 执行”串成闭环。
3. 功能表达很具体：
   - 多维采集
   - 区域引导
   - 清理垃圾/保留常用品/取出收纳盒
   - 拍照上传记录
   - 前后对比
   - 一键获取同款方案
   - 日程管理/个人中心/成就类沉淀
4. 视觉风格很统一：
   - 浅底色
   - 暖棕 + 橙色强调
   - 大留白
   - 手机屏幕作为核心视觉锚点
   - 文字是辅助，不是主角

## 当前 app 的主要问题
### 1. 视觉层级偏弱
现在首页是标准 `TabView + Card` 的组合，信息能看懂，但没有视频里的那种“产品感”和“步骤感”。  
启动截图里能看出：
- 版式还算干净，但太像普通 Demo
- 首屏靠卡片堆叠，没有明确的主叙事
- 预览图、说明文字、操作按钮之间的关系还不够强

### 2. 真实能力没有被真实素材验证
代码里虽然有 `VisionScanService`、`RoomPlan`、`ARKit`，但很多地方仍在用演示兜底：
- `DemoRoomPreview(progress:)`
- `DemoData.snapshot`
- 占位式的前后对比和空间示意

这会导致一个很严重的问题：界面看起来像“支持识别”，但实际验证不到真正的识别能力。

### 3. 交互闭环不够完整
视频里是“看到问题 -> 立即采集 -> 立即生成方案 -> 立即按步骤执行 -> 回收成果”。  
现在 app 虽然功能点都有，但链路分散，缺少这种强引导式节奏。

### 4. 测试方式不对
你说得对，拿假的文字图、伪造图片去测，基本测不出 AR 识别能力和视觉识别能力。

真正应该测的是：
- 真实房间照片
- 真实桌面杂物照片
- 真实书桌/床边/衣柜照片
- 实拍视频截帧
- 相机实时拍摄
- RoomPlan 真机扫描

## 开发方向
### P0：先把“真实测试”补齐
- 收集一批真实图片素材，按场景分组
- 每个场景至少包含：
  - 整体远景
  - 中景
  - 局部细节
  - 整理前/后对照
- 用这些素材验证：
  - Vision 识别结果
  - 物品分类准确性
  - 方案生成是否合理
  - 页面是否能承载真实识别结果

### P1：把首页改成“产品主场”
- 首屏直接展示最强成果，不要先丢一堆平铺卡片
- 保留视频里那种“空间状态 + 下一步动作”的节奏
- 强化大图、步骤进度、前后对比、引导按钮

### P2：把扫描页做成“真采集页”
- 默认展示真实摄像/相册输入入口
- 取消或弱化纯演示图的存在感
- 把识别结果、置信度、建议区域、待确认状态做得更像真实工作流

### P3：把执行页做成“行动清单”
- 每一步对应明确区域和动作
- 当前步骤高亮
- 完成后立刻回到成果沉淀

### P4：把成果页做成“可展示资产”
- 前后对比
- 标签摘要
- 成就/档案
- 社区案例复用

## 代码层建议
- 保留 `VisionScanService` 和 `ARKit`，但测试必须切到真实图片
- 把 `DemoRoomPreview` 明确收敛成兜底，而不是主展示
- 把 `Space / Capture / Execution / Community / Profile` 的信息架构再压一遍，让每个页面职责更清楚
- 给视频里的关键画面建立对应的 UI 状态清单，逐个实现和对照

## 下一步最该做的事
1. 按视频逐帧整理“页面清单”
2. 给每个页面标注：目的、核心信息、交互、素材类型
3. 用真实照片重跑扫描与规划
4. 再按视频风格重做首页、扫描页、执行页

如果继续往下做，我建议直接从“视频分镜 -> 页面状态表 -> 真实素材测试集”这条线推进，不要再用假图验证核心能力了。
