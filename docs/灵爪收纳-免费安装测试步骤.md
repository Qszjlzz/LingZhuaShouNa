# 灵爪收纳免费安装测试步骤

这是一份给测试人员的安装说明。

使用 AltStore 在 iPhone 上安装测试版 App。

## 重要前提

测试人员必须准备：

- 一部 iPhone；
- 一台 Mac 或 Windows 电脑；
- 一根可以传输数据的数据线；
- 自己的 Apple ID；
- iPhone 已连接网络；
- 至少约 1GB 可用存储空间。

只有 iPhone、没有电脑时，不能完成这个免费安装流程。

## 你会用到的文件

测试人员需要拿到：

```text
SmartPaw.ipa
```

不要把 `.zip` 源码、`.xcarchive` 文件或模拟器 App 当作安装包。

IPA 文件需要由项目开发者通过网盘、iCloud Drive 或其他文件传输方式发送。不要通过会压缩文件内容的方式传输。

## 安全提醒

- AltServer 只从官方 AltStore 网站下载：<https://altstore.io/>。
- 安装时使用测试人员自己的 Apple ID。
- 不要把 Apple ID 密码发给项目开发者或第三方网站。
- 不要使用来路不明的“在线签名”网站。

## 第一步：开启 iPhone 开发者模式

在 iPhone 上打开：

```text
设置 → 隐私与安全性 → 开发者模式
```

打开“开发者模式”，按照系统提示重新启动 iPhone。

如果找不到“开发者模式”：

1. 先用数据线连接 iPhone 和电脑；
2. 解锁 iPhone；
3. 手机弹出“信任此电脑”时，点击“信任”；
4. 输入 iPhone 锁屏密码；
5. 再回到“设置 → 隐私与安全性”查找“开发者模式”。

## 第二步：下载 AltServer

在电脑浏览器打开：

<https://altstore.io/>

根据电脑系统下载对应版本：

- Mac：下载 macOS 版本；
- Windows：下载 Windows 版本。

安装完成后，打开 AltServer。它通常不会显示一个普通窗口，而是出现在：

- Mac 顶部菜单栏；
- Windows 右下角任务栏的隐藏图标区域。

## 第三步：安装 AltStore

### Mac 操作

1. 打开 AltServer；
2. 用数据线连接 iPhone；
3. 解锁 iPhone；
4. 如果出现“信任此电脑”，点击“信任”；
5. 点击 Mac 顶部菜单栏的 AltServer 图标；
6. 选择：

```text
Install AltStore → 你的 iPhone
```

7. 输入测试人员自己的 Apple ID 和密码；
8. 等待安装完成。

如果 Mac 要求安装 Mail 插件：

1. 在 AltServer 菜单中选择 `Install Mail Plug-in`；
2. 打开 Mac 的“邮件”App；
3. 进入：

```text
邮件 → 设置 → 通用 → 管理插件
```

4. 勾选 AltPlugin；
5. 重启“邮件”和 AltServer；
6. 再次执行 `Install AltStore`。

### Windows 操作

1. 按 AltStore 官方页面的说明安装 AltServer；
2. 如果安装程序提示需要 Apple 组件，按提示安装 iCloud 和 iTunes；
3. 打开 iCloud，并登录测试人员自己的 Apple ID；
4. 打开 AltServer；
5. 用数据线连接 iPhone；
6. 解锁 iPhone，并点击“信任此电脑”；
7. 点击 Windows 右下角任务栏中的 AltServer 图标；
8. 选择：

```text
Install AltStore → 你的 iPhone
```

9. 输入测试人员自己的 Apple ID 和密码；
10. 等待安装完成。

如果 Windows 版 AltServer 提示缺少 iCloud、iTunes 或 Apple 驱动，按照提示安装后重新打开 AltServer。

## 第四步：信任 AltStore

安装完成后，iPhone 桌面会出现 `AltStore`。

如果打开 AltStore 时提示无法验证开发者，打开：

```text
设置 → 通用 → VPN 与设备管理
```

找到对应的开发者账号，点击“信任”。不同 iOS 版本的名称可能显示为“设备管理”。

然后打开 AltStore，使用刚才安装时使用的同一个 Apple ID 登录。

## 第五步：把灵爪收纳 IPA 传到 iPhone

项目开发者会把 `SmartPaw.ipa` 发给测试人员。可以使用网盘、iCloud Drive 或其他文件传输方式。

下载完成后：

1. 打开 iPhone 的“文件”App；
2. 找到 `SmartPaw.ipa`；
3. 长按这个文件；
4. 点击“共享”；
5. 在分享列表中选择 `AltStore`；
6. 等待 AltStore 完成安装。

如果分享列表中没有 AltStore：

1. 打开 AltStore；
2. 进入 `My Apps`；
3. 点击右上角的 `+`；
4. 在“文件”中选择 `SmartPaw.ipa`；
5. 等待安装完成。

安装成功后，iPhone 桌面会出现“灵爪收纳”。

## 第六步：第一次打开灵爪收纳

第一次打开 App 时，请允许以下权限：

- 相机：用于拍摄和实时识别；
- 照片：用于选择收纳场景图片；
- 通知：用于日程提醒；
- 本地网络：如果系统弹出提示，可以允许。

然后可以测试：

1. 空间首页；
2. 拍摄或导入桌面图片；
3. AI 物品识别；
4. 修改识别结果；
5. 生成收纳计划；
6. 分步骤执行；
7. AR 引导；
8. 完成记录和社区功能。

## 第七步：免费账号的 7 天限制

免费 Apple ID 签名通常只能让 App 使用约 7 天。到期前需要刷新签名。

刷新时：

1. iPhone 和电脑连接同一个 Wi-Fi；
2. 电脑保持开机；
3. 电脑上的 AltServer 保持运行；
4. 打开 iPhone 上的 AltStore；
5. 进入 `My Apps`；
6. 点击灵爪收纳旁边的刷新按钮。

建议在到期前一天刷新，不要等 App 已经无法打开后再处理。

如果长期测试，需要保留安装 AltServer 的那台电脑。没有电脑时，免费签名无法稳定续期。

## 常见问题

### 找不到 iPhone

- 确认 iPhone 已解锁；
- 确认数据线支持数据传输，不只是充电；
- 重新点击“信任此电脑”；
- 关闭并重新打开 AltServer；
- Windows 检查 iCloud、iTunes 和 Apple 驱动是否安装。

### AltStore 打不开

进入：

```text
设置 → 通用 → VPN 与设备管理
```

找到开发者账号并点击“信任”。

### IPA 安装失败

- 确认下载的是完整的 `SmartPaw.ipa`；
- 不要使用聊天软件压缩或改名后的文件；
- 确认 iPhone 有足够存储空间；
- 确认 AltStore 已经用同一个 Apple ID 登录；
- 删除旧版本后重新导入 IPA。

### App 打开后马上退出

- 确认 iPhone 系统达到 App 要求的 iOS 18.0；
- 确认免费签名没有过期；
- 在 AltStore 中刷新 App；
- 如果仍然失败，把错误截图和 iPhone 型号发给项目开发者。

### 能不能把 Apple ID 给开发者

不建议。测试人员应当使用自己的 Apple ID 在自己的电脑上完成 AltStore 安装和签名。

## 完整流程

```text
准备 iPhone、电脑、数据线和自己的 Apple ID
→ 开启 iPhone 开发者模式
→ 电脑下载并打开 AltServer
→ 数据线连接 iPhone 并信任电脑
→ AltServer 安装 AltStore
→ iPhone 信任开发者并打开 AltStore
→ 下载 SmartPaw.ipa
→ 通过“文件 → 共享 → AltStore”导入
→ 安装并打开灵爪收纳
→ 7 天内通过 AltStore 刷新签名
```
