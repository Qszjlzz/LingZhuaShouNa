# 隐私政策与支持页草稿

本文是上线前交给法务和产品确认的内容草稿，不是法律意见，也不是可直接填写的 URL。当前没有公开隐私政策 URL、支持 URL 或支持邮箱，提交状态为 BLOCKED。公开发布前必须补齐运营主体、联系方式、服务商、保留期限、删除流程和生效日期，并由真实 HTTPS 页面承载。

## 隐私政策应覆盖的事实

1. **相机与图片**：相机用于拍摄整理场景；用户从系统照片选择器选取图片。默认的本地识别在设备上运行；图片和识别结果写入 App 沙盒用于展示、历史和方案生成。说明删除空间/图片的路径和备份清理行为。
2. **可选云端 AI**：用户主动打开 AI 设置并填写自己的服务密钥后，拍摄图片和提示词会发往用户选择的第三方兼容接口（可能是 OpenAI、阿里云、智谱、硅基流动或用户自填服务）。说明第三方名称由用户选择、处理地域、留存期限、服务商条款、关闭方式和删除/撤回方式。没有 Key 或关闭开关时，拍照识别不应发送网络请求。
3. **密钥**：密钥保存在系统钥匙串，不应写入日志、快照、崩溃报告或 App 包；用户可在设置中替换或删除。仓库中曾出现 `Resources/llm-defaults.json` 的本地密钥文件，已从 Xcode 资源引用移除；发布前应撤销该旧密钥。
4. **诊断与本地设置**：`UserDefaults` 只保存语言/本地偏好；其 Required Reason API 使用已在 `PrivacyInfo.xcprivacy` 声明。manifest 已把可选云端发送的照片、物品描述及对话内容标为 App Functionality；App Store Connect App Privacy 问卷仍需根据真实云服务、留存、处理地区和第三方再利用逐项回答，不能把 manifest 的声明当作“没有收集”。
5. **儿童、追踪和广告**：当前仓库没有广告 SDK 或 ATT 调用。产品方需确认目标年龄、是否收集分析数据、是否向第三方分享，以及是否面向儿童；不能在政策中写成未验证的承诺。

## 首次启用云端 AI 的产品文案草稿

> 云端识别会把你选择的照片发送到你填写的第三方 AI 服务，用于识别物品和生成方案。服务商、处理地区和留存期限以隐私政策及其条款为准。你可以关闭云端 AI，改用设备端识别。是否继续？

当前代码已在保存云端开关前要求用户明确继续；审核前仍应在真机上验证关闭开关确实没有网络请求，并补齐真实服务商、处理地区、留存期限和删除方式。
