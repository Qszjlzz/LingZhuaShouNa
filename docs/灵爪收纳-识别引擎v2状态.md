# 识别引擎 v2 状态

更新时间：2026-08-03

## 当前链路

相机图像先进入 YOLO 实例分割，执行 0.50 置信度过滤、同类 NMS 和最多 10 个结果限制，再保留 raster mask。检测区域可以继续送入 MobileCLIP 图像编码器，向量库搜索会返回 Top-3 类别。

`SemanticRecognitionScanService` 在语义资源不完整时只返回 YOLO 结果，不生成随机向量，也不伪造 MobileCLIP 标签。`RecognitionResult.source` 用于区分 `.yolo` 回退和 `.mobileCLIP` 结果。

## 本轮修正

- 兼容官方 MobileCLIP S0/S1 的资源名 `mobileclip_s0_image.mlmodelc` 和 `mobileclip_s1_image.mlmodelc`。
- 根据 Core ML 图像约束读取输入尺寸；官方 S0/S1/S2 使用 256 x 256，BLT 使用 224 x 224。
- 优先读取官方输出 `final_emb_1`，再兼容旧的 `embedding` / `image_embedding` 输出名。
- `RecognitionResult` 现在可以携带 Top-2/Top-3 备选匹配和识别来源。
- YOLO 后处理上限统一为 10 个检测。

## 资源验收

当前工程已经加入以下真实资源：

- `mobileclip_s0_image.mlpackage`
- `mobileclip_s0_text.mlpackage`
- 官方 CLIP tokenizer 资源
- 由同一 MobileCLIP 文本编码器生成的 14 类 `category_embeddings.json`

模拟器真实模型冒烟测试已通过，完整 10 图语义基线为：场景类别命中率 60%，平均每图 2.5 个候选，平均语义匹配分数 21%。这不是逐物体 precision/recall；其中 3 张图片仍因 YOLO 没有产生候选而为空。真机仍需用现场相机帧复测延迟、发热和检测稳定性。
