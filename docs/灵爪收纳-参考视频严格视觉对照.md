## 严格结论

当前版本已经属于同一种“相机扫描 + 实例 mask + 拍摄控制区”的交互形态，但不能判断为完全一致。

| 维度 | 参考视频 | 当前 App | 判断 |
| --- | --- | --- | --- |
| 主画面 | 纵向相机画面占据扫描页主体 | 独立真实照片按 `aspectFill` 铺满扫描区 | 基本一致 |
| 顶部控制 | 关闭、扫描模式、录制状态 | 关闭、AR 扫描、REC | 基本一致 |
| Mask | 多色半透明实例 mask，边缘贴合物体 | YOLO raster mask，坐标正确但细边较粗 | 部分一致 |
| Box | 没有传统矩形检测框 | 没有 box | 一致 |
| 标签 | 视频后段存在物体标签 | 按产品要求只显示 mask，不显示标签 | 有意不同 |
| 底部控制 | 缩略图、计数/状态、录制、完成 | 缩略图、识别数量、停止、完成 | 基本一致 |
| 动态感 | 真机镜头移动，mask 随画面更新 | 模拟器使用静态独立照片 | 不一致，需真机验收 |
| 边界质量 | 大物体轮廓连续，视觉上较平滑 | 电脑、杯子、椅子贴合；线缆、书页仍粗 | 未完全达到 |
| 整体色调 | 浅色控制区、暖橙强调、相机内容主导 | 浅色控制区、橙色完成、照片主导 | 基本一致 |

## 素材隔离

- App 运行时只使用：
  - `external-messy-desk-note.png`
  - `external-cluttered-study-pexels.jpg`
  - `external-trash-room-imweb.jpg`
- `DemoData`、采集快捷入口、规划页、社区案例、模拟器启动参数和 XCTest 均已迁移到独立照片。
- 旧持久化数据中的 `SmartPawVideo*` asset 与对应本地图片名称会在加载时清除或替换。
- 参考视频及抽帧仅保留在 `video-analysis/` 和文档中用于开发对照，不作为 App 展示素材或识别测试输入。

## 尚未达到参考的原因

1. 当前 YOLO11n-seg 的 mask proto 为 `320×320`，无法恢复线缆、笔尖和书页等细边。
2. 模拟器无法证明相机移动时的 mask 稳定、抖动和空间锚定效果。
3. 当前未接入 EdgeSAM/MobileSAM 二阶段边缘细化模型。

## 下一验收门槛

- EdgeSAM/MobileSAM 接入后，在独立真实照片集上测 mask IoU 和 Boundary F-score。
- 真机相机连续移动 30 秒，检查 mask 漂移、跳变、延迟和发热。
- App 包扫描必须保持 `SmartPawVideo` 资源为零。
